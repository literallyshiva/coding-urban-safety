# Safety refinement — preview candidate

Based on `coding-urban-safety-approved-safety-ui.zip`.

- Desktop form width reduced from 48% to 45% on large screens.
- More expressive, consistent colored Material faces instead of OS-dependent emoji glyphs.
- Stronger selected rating state and illustrated condition icon chips.
- Less empty vertical spacing and better selection contrast.
- Original Safety illustration lightly sharpened, **not replaced by a native 4K asset**. The image still has limited source detail.
- All eight condition strings, rating values, Firestore state, navigation and validation remain unchanged.
- No new dependencies.

**Not Flutter-compiled or browser-tested.** Test on a new Vercel Preview branch before merging.
